# Foundation Time & Resource

Gemeinsames Modell für buchbare oder zuteilbare Ressourcen: Zimmer, Personal,
Fahrzeuge, Geräte, Lagerplätze, Behandlungsräume und Kapazitätspools.

Enthalten: Zeitzone, ausgewertete Verfügbarkeitsregeln, Kapazität, Blackouts,
ablaufende Holds, Bestätigung, Stornierung, Ressourcenpools, atomare
Mehrfachzuweisung und Konfliktprüfung.
