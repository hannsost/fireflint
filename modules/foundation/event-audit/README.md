# Foundation Event & Audit

Gemeinsame Hüllen für Domain-/Integration-Events und append-only Audit.
Enthalten sind Korrelation, Causation, Actor, Subject, Eventschema-Versionen,
Inbox-Deduplikation, Outbox-Zustellung, Lease-Recovery, Retries/Dead Letter,
Korrelationsabfragen und ein Referenz-Integritätsnachweis.
