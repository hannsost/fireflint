# Foundation Party

Universelles Modell für Personen, Organisationen, Einheiten und Standorte.
Kunde, Lieferant, Patient, Bürger, Mitarbeiter oder Mandant sind Rollen einer
Party und keine eigenen Personenstammdaten.

Enthalten: Identifikatoren, bevorzugte Kontaktpunkte, Adressen, Rollen mit
Lebenszyklus, transitive Hierarchien, Beziehungen, Dubletten, Merge-Vorschau
und Merge-Vertrag.
