# Foundation Work

Universelle operative Arbeit: Cases, Tasks, Queues, Abhängigkeiten,
Zuweisungen, SLA-Ziele, Fristen, Eskalationen, strukturierte Notizen,
Entscheidungen und Links auf Domänenobjekte.

Forms, Privacy, Commerce und EDI sollen fachliche Vorgänge verknüpfen, aber
keine eigenen allgemeinen Task- und Case-Grundmodelle pflegen.
