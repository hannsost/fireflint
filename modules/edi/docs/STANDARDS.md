# Standards und Quellen

Das Modul kopiert keine Standards. Produktive Provider müssen offizielle,
lizenzkonforme Artefakte verwenden.

- UN/EDIFACT: https://unece.org/trade/uncefact/introducing-unedifact
- ASC X12 Transaction Sets: https://x12.org/products/transaction-sets
- Peppol BIS Billing 3.0: https://docs.peppol.eu/poacc/billing/3.0/
- XRechnung: https://xeinkauf.de/xrechnung/

Stand der Recherche: 19. Juni 2026. Die Peppol-Dokumentation weist aktuell den
November-2025-Release für BIS Billing 3.0 aus. Releases bleiben trotzdem
Konfiguration der Partnervereinbarung und werden nicht im Core festgeschrieben.
