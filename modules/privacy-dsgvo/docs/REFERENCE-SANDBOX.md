# Referenz-Sandbox

## Szenarien

- Auskunft über Content, Commerce, Forms und EDI
- Löschung optionaler Daten und Anonymisierung aufbewahrungspflichtiger Daten
- Marketing-Consent-Widerruf ohne Beeinflussung vertraglicher Verarbeitung
- B2B-Geschäftskontaktdaten im EDI-Export
- DSFA-Nachweis für formale B2G-Prozesse
- Datenschutzvorfall mit technischer Berechnung einer 72-Stunden-Arbeitsfrist

## Grenzen

- keine rechtliche Bewertung von Rechtsgrundlagen oder Aufbewahrungsfristen
- keine produktive Identitätsprüfung
- keine Daten-Dritter-Filterung
- keine sicheren Exportarchive
- keine Backuplöschung
- keine echte Anonymisierungsprüfung
- keine automatische Meldung an Aufsichtsbehörden oder Betroffene

Die Sandbox ist ausführbare Dokumentation. Fachliche und juristische Prüfungen
bleiben zwingend.
